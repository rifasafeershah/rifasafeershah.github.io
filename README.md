# Rifa Safeer Shah — Portfolio

Personal portfolio website for cybersecurity, data analytics, product management, and education.

## Local preview

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy with GitHub Pages

1. Create a public repository named `rifasafeershah.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. Visit `https://rifasafeershah.github.io` after deployment completes.

## Updating content

Edit `index.html` for content, `style.css` for appearance, and `script.js` for mobile navigation. Commit changes to `main` to redeploy.

## Privacy

The contact section contains a public email address and telephone link. Remove the telephone link if you do not want your number published.
